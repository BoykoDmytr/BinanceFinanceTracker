# 📈 CryptoFinance Tracker

Мобільний застосунок (Android) для трекінгу прокрутів Binance Alpha: журнал, P&L,
бали, кольорова статистика, нагадування і заготовки постів. Уся історія з
Excel-таблиці (01.07.2026 – 21.08.2026) вже вшита в застосунок і з'являється при
першому запуску.

## Як отримати APK

1. Відкрий [Releases → apk-latest](../../releases/tag/apk-latest) (або вкладку
   **Actions** → останній запуск **Build Android APK** → артефакт
   `cryptofinance-tracker-apk`).
2. Скачай `cryptofinance-tracker.apk` на телефон і відкрий файл.
3. Android запитає дозвіл на встановлення з невідомих джерел — дозволь.
4. Після першого запуску дозволь сповіщення, інакше нагадування не приходитимуть.

APK збирається автоматично GitHub Actions'ом на кожен push у гілку.

## Що всередині

| Вкладка | Що робить |
|---|---|
| **Дашборд** | Баланс, бали, P&L і ROI в кольорах; теплова карта активності (зелений — крутив, золотий — дроп, червоний — пропустив) з прокруткою по місяцях/роках; результати по місяцях; графіки балансу/балів/обсягу з сіткою значень; прогноз балів; статистика; списки дропів і бустерів |
| **Журнал** | Один запис на день: обсяг, комісія, бали ±, дохід з дропу, дохід з бустерів, газ, коментар. Баланс і залишок балів рахуються самі — за тими ж формулами, що в таблиці. Кнопка «Підсумок за 15 днів» — стислий проміжний результат |
| **Нагадування** | Вбудоване «прокрут»: якщо за сьогодні немає запису — пуш у заданий час (+повтор через 2 год). Плюс кастомні: щодня / по днях тижня / разово |
| **Пости** | Заготовки постів з картинками: чернетка → копіювання тексту одним тапом, шеринг картинок → статус «опубліковано». До поста можна прив'язати нагадування — тап по пушу відкриває пост |
| **Налаштування** | Акаунти (додати, назвати, перемкнути активний), стартовий баланс/бали і бали за день для кожного акаунта, поточний баланс (корекція) окремо від стартового, експорт журналу в CSV (бекап) та імпорт CSV назад |

## Результати по місяцях

Блок на дашборді: кожен календарний місяць окремим рядком з P&L і кількістю
активних днів («28 з 30»). Тап розгортає деталі: обсяг, комісії, газ, дропи,
бустери, ROI, корекції, баланс на початок → на кінець місяця і залишок балів.
Місяці без жодного запису теж показуються — з нулями, щоб пропуск було видно.
Поточний місяць позначено «триває» і рахується по сьогодні.

## Поточний баланс і корекції

Баланс не зберігається, а рахується з журналу. Якщо реальний баланс на Binance
розійшовся з розрахованим (депозит, вивід, зміна курсу), не чіпай стартовий
баланс — він зсуне всю історію. Натомість: **Налаштування → ✎ → Поточний
баланс** — введи фактичну суму, і різниця запишеться **корекцією за сьогодні**.

- Історія до сьогодні, стартовий баланс і P&L операцій не змінюються; на
  графіку балансу — сходинка в день корекції.
- Повторне встановлення в той самий день не додає нову корекцію, а перераховує
  сьогоднішню.
- Вводь поточний баланс, коли сьогоднішній прокрут уже записано — інакше
  комісію дня буде враховано двічі.
- Список корекцій — там само, під полем; ✕ прибирає корекцію. У журналі день з
  корекцією показує її суму і баланс після неї.
- Корекції входять в експорт/імпорт CSV (колонка «Корекція балансу, $»).

## Кілька акаунтів

Якщо акаунтів Binance кілька (на різних телефонах), кожен ведеться окремо: свій
журнал, стартовий баланс і бали. Назву задаєш сам — так, щоб було зрозуміло, де
він: «Samsung A54», «телефон мами» тощо.

- **Налаштування → Акаунти**: тап по акаунту робить його активним, ✎ — змінити
  назву і стартові значення, «+ Додати акаунт» — новий.
- **Дашборд** показує блок «Усі акаунти»: чи прокручено сьогодні (✓/✗), баланс,
  бали, P&L і стрік кожного, плюс сумарний баланс і P&L. Тап по рядку — деталі
  цього акаунта нижче. Бали не підсумовуються: у кожного акаунта вони свої.
- **Журнал** має перемикач акаунтів угорі; у формі запису видно, в який акаунт
  він піде.
- **Нагадування «прокрут»** спрацьовує, поки хоча б один акаунт не записаний за
  день, і перелічує, які саме. Тап відкриває журнал першого з них. Для акаунта,
  який більше не крутиш, нагадування можна вимкнути в його налаштуваннях.
- **Експорт/імпорт CSV** працює з активним акаунтом (окремий файл на акаунт).

При оновленні зі старої версії весь наявний журнал автоматично потрапляє в
«Основний акаунт» — його можна просто перейменувати.

Дані зберігаються **лише локально** на телефоні (SQLite). Жодних серверів,
логінів чи API-ключів. Перед перевстановленням застосунку зроби експорт CSV для
кожного акаунта — і імпортуй їх назад після встановлення.

## Формули (як у таблиці)

- Баланс = стартовий баланс − Σкомісій − Σгазу + Σдропів + Σбустерів + Σкорекцій
- Бали = стартові бали + Σ(бали+) − Σ(бали−)
- P&L операції = Σдропів + Σбустерів − Σкомісій − Σгазу (корекції не входять)
- ROI = P&L / (Σкомісій + Σгазу)

Контрольні цифри звіряються тестом: `npm run test:calc`.
