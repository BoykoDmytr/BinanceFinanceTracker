# 🐝 Crypto Hornet

Мобільний застосунок (Android) для трекінгу прокрутів Binance Alpha: журнал, P&L,
бали, кольорова статистика, нагадування і заготовки постів. Уся історія з
Excel-таблиці (01.07.2026 – 21.08.2026) вже вшита в застосунок і з'являється при
першому запуску.

## Як отримати APK

1. Відкрий [Releases → apk-latest](../../releases/tag/apk-latest) (або вкладку
   **Actions** → останній запуск **Build Android APK** → артефакт
   `crypto-hornet-apk`).
2. Скачай `crypto-hornet.apk` на телефон і відкрий файл.
3. Android запитає дозвіл на встановлення з невідомих джерел — дозволь.
4. Після першого запуску дозволь сповіщення, інакше нагадування не приходитимуть.

APK збирається автоматично GitHub Actions'ом на кожен push у гілку.

## Що всередині

| Вкладка | Що робить |
|---|---|
| **Дашборд** | Баланс, бали, P&L і ROI в кольорах; теплова карта активності (зелений — крутив, золотий — дроп, червоний — пропустив); графіки балансу/балів/обсягу; прогноз балів; статистика; список дропів |
| **Журнал** | Один запис на день: обсяг, комісія, бали ±, дохід з дропу, газ, коментар. Баланс і залишок балів рахуються самі — за тими ж формулами, що в таблиці |
| **Нагадування** | Вбудоване «прокрут»: якщо за сьогодні немає запису — пуш у заданий час (+повтор через 2 год). Плюс кастомні: щодня / по днях тижня / разово |
| **Пости** | Заготовки постів: чернетка → копіювання одним тапом → статус «опубліковано». До поста можна прив'язати нагадування — тап по пушу відкриває пост |
| **Налаштування** | Стартовий баланс/бали, бали за день, експорт журналу в CSV (бекап для Excel) |

Дані зберігаються **лише локально** на телефоні (SQLite). Жодних серверів,
акаунтів чи API-ключів.

## Формули (як у таблиці)

- Баланс = стартовий баланс − Σкомісій − Σгазу + Σдоходів з дропів
- Бали = стартові бали + Σ(бали+) − Σ(бали−)
- P&L операції = Σдропів − Σкомісій − Σгазу
- ROI = P&L / (Σкомісій + Σгазу)

Контрольні цифри звіряються тестом: `npm run test:calc`.

## Розробка

```bash
npm install
npm start            # Expo dev server (Expo Go або dev-клієнт)
npm run typecheck    # перевірка TypeScript
npm run test:calc    # звірка розрахунків з Excel-таблицею
```

Стек: Expo SDK 57 (React Native), expo-router, expo-sqlite, expo-notifications,
react-native-svg.
